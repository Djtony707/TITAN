# TITAN v8 — North Star

*The product vision v8 is built to deliver. Distilled from the owner's direction,
August 2026.*

## The feeling

> "It feels like you're working with a real team of people, not AI agents."

That is the bar. Not "a powerful framework" — a *company you enjoy working with*.
Everything below serves that feeling.

## What a user can do

1. **Shape any agent.** Choose the agent's *type* (what specialist it is), what it
   *does* (its role, tools, scope), and which *harness* it runs on
   (`claude-agent-acp`, `codex-acp`, `goose`, `buzz-agent`, or a custom command).
   The harness is a per-agent choice, not a global one — Block's own
   remote-agents spec calls this the "configurable harness" requirement, and v8
   exposes it as a first-class setting.
2. **Create agents directly** — spin up a new teammate from a persona + role +
   harness + model, with its own identity and memory stream.
3. **Or delegate creation to a meta-agent** — appoint one agent (the "chief of
   staff" / hiring manager, in the spirit of Eli) that can create, configure,
   promote, and retire other agents on the user's behalf. The user manages one
   relationship; that agent manages the rest of the company.

## Groundbreaking, without breaking TITAN

The company must feel alive, and every v7 user's setup must keep working
untouched (40k+ installs — backward compatibility is non-negotiable). The
"alive" comes from the two unbuilt slices:

- **Slice 7 — the company brain + hiring flow.** Pooled, attributed memory
  (FTS + embeddings + graph) so what one teammate learns, the team knows, and
  you can see *who* learned it. The hire/fire flow and promotion
  comparator/driver make the meta-agent's "create/promote/retire" real. This is
  the substrate the whole feeling rests on.
- **Slice 8 — the social layer.** Growth moments ("Forge just learned X"),
  huddles, and a dashboard that reads like a team space, not a control panel.
  This is what turns a correct system into one that *feels* like colleagues.

## The principle that keeps it honest

Progressive trust (already built into slices 4–6): agents earn autonomy through
shadow trials and gated activation. A meta-agent that can create teammates is
powerful — so the same gates apply to what it creates. Groundbreaking capability,
governed. The signature/lifecycle repair currently underway is the foundation
this rests on: the self-compiling loop must actually work before the company can
learn.
